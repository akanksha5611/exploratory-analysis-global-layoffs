\## Exploratory Data Analysis (EDA) – Global Layoffs



This project performs exploratory data analysis (EDA) on a cleaned global layoffs dataset.

The goal is to understand trends, patterns, and insights related to layoffs across

companies, industries, countries, and time periods.



\### Data Source

The dataset used in this project is a cleaned version of the global layoffs data.

Data preparation and cleaning were performed in a separate data cleaning project.

This repository focuses only on analysis and does not modify the data.



\### Analysis Scope

The analysis includes:

\- Overall dataset overview

\- Time-based trends

\- Company-level analysis

\- Industry-level analysis

\- Country-level analysis

\- Key insights and observations
